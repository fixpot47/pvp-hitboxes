# PVP Hitboxes

PVP Hitboxes is a client-side Fabric mod for configurable combat hitbox rendering.

It is based on **Combat Hitboxes** by **Sootysplash** and preserves the original mod's behavior while updating the project for Minecraft 26.3 and using the PVP Hitboxes branding.

Original project: https://github.com/sootysplash/combat-hitboxes

## Requirements

- Fabric API
- Cloth Config API
- Text Placeholder API
- FixLib

Mod Menu is optional and provides access to the configuration screen.
